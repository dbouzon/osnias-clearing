Transfer Rule

Security invariant

A P2P ORUSD transfer can only be initiated from a clearing instruction already received and accepted by the connected account. The transaction is signed by that wallet. After confirmation, the ORUSD transaction hash is recorded against the instruction, whose execution state is then visible through the clearing Registry.
