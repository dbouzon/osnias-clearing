Add a B2B multilateral netting capability to your software.

Osnias Clearing invites ERP vendors, accounting software providers and e-invoicing operators to help design an API integration for multilateral netting of commercial obligations.

Complementing electronic invoicing

ERP systems already record invoices, due dates and payments. Osnias aims to process accepted commercial obligations through synchronized multilateral netting cycles and produce net positions for bank settlement. It does not replace regulated e-invoicing platforms or tax reporting obligations.

Proposed integration interfaces

  • Submit and monitor B2B obligations with identifiers, amounts, currency and due date.
  • Track acceptance, cycle participation and net positions.
  • Receive cycle-close events, reconcile settlements and handle exceptions.
  • Connect banking services through adapters outside the portable EVM Core.

A pilot co-designed with vendors

The program seeks three to four software vendors to participate in Clean Code development, a shared proof of concept, integration testing and a security audit. APIs, pilot governance and financial contributions will be agreed contractually.
